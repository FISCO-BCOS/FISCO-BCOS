# --- pre-Byzantium receipts ------------------------------------------------------------------
# Before Byzantium a receipt's first field is the post-transaction state root, not the status
# byte; computing it needs an MPT root after every transaction, which the block pipeline
# builds once per block. Receipts root (and so every block) of those forks mismatches. The
# verifier compares the receipts root before gasUsed and the state root, so this entry also
# hides an execution regression in these forks for any block that carries a transaction.
