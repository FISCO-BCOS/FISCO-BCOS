## 本会话发现的未修问题（记录待办）

1. **extraTransactionBytes 信封布局错位**（TransactionResponse 解码路径）：`toTransaction()` 存 `encodeForSign()` 形态，但响应解码按 wire 形态（[..., v, r, s]）读 → chainId 槽读到 v 全值 → JSON chainId=0x1bebce（应为 0xdf5d5）。当前 v 修复输出结构一致的对（能过 op-geth 校验），但 **tx hash 与原始不一致**（重编码≠原始字节）。需要统一信封规范后重修。
2. **L2StandardBridge.withdraw 空 revert**：bridge→messenger→passer 链路版本一致性待查（passer 已是 1.2.0 新 API；怀疑 messenger impl 调旧选择器）。原生 initiateWithdrawal 可用，不阻塞。
3. **eth_feeHistory 未实现**（cast 默认 EIP-1559 发现失败；用 `--legacy --gas-price` 绕过）。
4. **块 JSON 缺 `miner` 字段**（alloy/cast 反序列化失败，receipt 轮询报错；用 `--async` 绕过）。
5. **历史状态读瞬时不一致**：MPT 历史读路径曾对同一 block tag 返回漂移值（1000/10000/10001），后收敛稳定。疑似缓存/视图滞后，需复现定位。
6. **主仓库 CallRequest.cpp 有未解决 merge conflict 标记**（`<<<<<<< Updated upstream`，与本分支无关但阻塞主仓库构建）。
