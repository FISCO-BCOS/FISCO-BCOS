## 4. §8 结构

### §8.1 总体结论
一句话总结论：FISCO OP 执行器**核心执行路径（阶段 0/3/4）与 op-geth v1.101702.2 逐位一致**，差异集中在**结构层设计（索引隔离/块校验位置/双执行器）**与 **Karst 未适配（D-2 🔴）**。

### §8.2 7 阶段三态判定表

| 阶段 | 聚合判定 | 依据（引用 DIVERGENCES 矩阵行） |
|---|---|---|
| 0 数据形态 | 等价 + 1 结构性 | 三次类型翻译（结构性，已确认） |
| 1 RPC 入口 | 等价 + 1 结构性 | V4 桩/V5 缺失（结构性，已确认） |
| 2 块校验 | 等价 + 1 结构性 | 承诺比对 vs VerifyHeader/ValidateBody（结构性，已确认） |
| 3 状态执行 | **等价** | 全部行已确认（D-1 交易级 + 快照契约 D-4 固化） |
| 4 块级收尾 | **等价** | B 台账全关闭（B-1/B-8 已修一致，其余已确认） |
| 5 落库 | 结构性差异 | 索引隔离（设计取舍，SYS_HASH_2_TX 不写） |
| 6 输出 | 等价 | block hash 承诺比对；output root 不在 EL 范围 |
